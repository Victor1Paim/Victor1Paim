# Memória do Estúdio Dev

Memória que vale em toda sessão (substitui o claude-mem, que perderia os dados
quando o contêiner da nuvem é apagado). São arquivos de texto: você pode ler e
editar à vontade.

| Arquivo | O que guarda |
|---|---|
| `preferencias.md` | Como o Victor gosta de trabalhar: estilo, gosto visual, ferramentas, o que evitar |
| `decisoes.md` | Decisões tomadas (data, decisão, motivo), mais nova no topo |
| `projetos.md` | Índice dos projetos: status, link, próximo passo |
| `aprendizados.md` | O que deu certo/errado (copy que converteu, bug recorrente, ferramenta que falhou) |

Regras de uso: skill `memoria`.
