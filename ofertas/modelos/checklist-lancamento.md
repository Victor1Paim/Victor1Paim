# Checklist de lançamento

## Conteúdo
- [ ] Preços, prazos, endereço e contato batem com o material oficial do cliente
- [ ] Nenhuma prova, número ou escassez inventados
- [ ] Copy revisada (skill `humanizer`) e sem erros de português

## Funcionamento
- [ ] Botões de compra / WhatsApp testados de ponta a ponta
- [ ] Formulário: obrigatórios certos, mensagens de erro claras
- [ ] Mensagem enviada ao WhatsApp organizada e completa
- [ ] Downloads (PDF, materiais) funcionando

## Visual e técnico
- [ ] Celular 390px e desktop 1440px sem rolagem lateral
- [ ] Modo escuro forçado não altera as cores (`color-scheme: only light`)
- [ ] CSS/JS com `?v=` atualizado
- [ ] Imagens leves (WebP), título, descrição e prévia de link (OG)
- [ ] Pixels e eventos de conversão (se houver)

## Publicação
- [ ] Deploy na Vercel e teste no endereço real
- [ ] Link curto / domínio definido
- [ ] QR code gerado e testado com leitor
- [ ] Memória atualizada (`estudio-dev/memoria/projetos.md`)
