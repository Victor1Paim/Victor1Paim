# Ofertas (estúdio)

Frente independente do Halftone e do Desvendando Ideias: pesquisa, criação e lapidação
de ofertas (infoprodutos, serviços, produtos físicos, cardápios, sazonais, lançamentos).

- Chat de ESTRATÉGIA: pesquisa, oferta, copy, plano de lançamento/conteúdo.
- Chat de PRODUÇÃO: página/site (HTML/CSS/JS ou Next.js, GSAP + Lenis, Vercel), carrinho
  para WhatsApp, PDFs, QR codes, imagens IA, TTS, trilha, reels (Remotion/HyperFrames).

## Fluxo
1. Briefing → 2. Pesquisa → 3. Oferta (aprovação de promessa, preço e garantia) →
4. Copy → 5. Divulgação (se pedido) → 6. Pacote de produção.

## Estrutura de cada projeto
```
ofertas/projetos/<slug>/
  briefing.md   # produto, público, preço, provas, canal, identidade, fora do escopo
  pesquisa.md   # dores, desejos, objeções, vocabulário, concorrentes (links), brecha
  oferta.md     # canvas aprovado
  copy.md       # página completa + microcopy + mensagem do WhatsApp
  producao.md   # o que a produção precisa para construir e o critério de pronto
```

## Regras
- Nada inventado: o que faltar vira [PREENCHER].
- Urgência só verdadeira. Fontes citadas; FATO separado de HIPÓTESE.
- Texto humano, sem cara de IA. Respeitar regras de anúncio (Meta/Google/TikTok).
- Mobile primeiro, visual premium com as cores do cliente.
